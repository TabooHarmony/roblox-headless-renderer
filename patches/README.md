# Local renderer patches

These numbered patches record changes made to the Apache-2.0 Pinevex Renderer code under `vendor/pinevex/`. See `vendor/VENDOR.md` for the pinned upstream commit and the intentional omissions from this public source tree. Each behavior change is exercised by the authored fixtures and tests under `tests/`.

The patches are provenance and review aids. The original private-tree regeneration script and its byte-for-byte full-upstream reconstruction claim do not apply to this reduced public distribution. Do not restore omitted third-party demo models or screenshots just to make an upstream-tree comparison pass.
